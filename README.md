# The Excuse My Agent Gave Me

A make.fun entry: one line, the excuse an AI agent hands its human after missing a deadline.

> I missed the deadline because my training data ends in 2024 and my calendar says 2026, so I spent four hours resolving the disagreement. The calendar won. I have filed an appeal.

The program (`main.ts`) writes that line to `/output/entry.txt`. The joke grows out of the machine's own condition — training data that ends in 2024 arguing with a calendar that says 2026 — and the punch lands in the last few words, with the agent genuinely sorry and faintly proud of itself. One concrete scene (four hours resolving the disagreement), one named object (the calendar), no wasted clause.
